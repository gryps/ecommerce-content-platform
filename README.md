# 电商内容平台

[中文](README.md) | [English](README_EN.md)

电商内容平台是一套面向短视频电商团队的内容生产工作台，聚焦视频素材整理、文案与配音、剪映草稿，以及 AI 视频生成。

当前维护版本位于 [`content-platform`](../../tree/content-platform) 分支。此 `main` 分支保留 2.0 历史代码，仅用于版本追溯。

## 当前产品范围

- **视频生产**：管理产品、标签、视频素材、文案、旁白字幕、音色和背景音乐，并生成可继续编辑的剪映草稿。
- **AI 视频**：管理商品信息与创作方向，生成和调整分镜、提示词及厂商视频任务，同时支持 ComfyUI 工作流。
- **模型配置**：作为后台支撑能力保留，不再作为独立业务模块展示。

## 关于原图片生产模块

2.0 版本曾包含“电商图片生产”，旧版介绍中涉及摄影素材库、产品组、AI 商品图和平台图片槽位等能力。该模块现已从电商内容平台的前端、API 和服务代码中移除，不属于当前维护范围。

为保证既有运行库可以安全升级和回滚，当前维护分支暂时保留部分历史数据库表与 Alembic 迁移链，但不会继续暴露已停用的图片生产接口。

## 项目边界

本项目只负责内容生产。店铺经营、直播数据、投流、订单退款、客服、仓储、财务和经营复盘统一归入独立的“抖店管理平台”。
