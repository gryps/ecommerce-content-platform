# 后续开发协作规范

本文档记录电商内容平台后续和 AI 编程助手协作的推荐方式。当前只维护“视频生产”和“AI 视频”两个业务模块；模型配置仅作为后台支撑能力，不作为独立模块展示。

## 推荐任务格式

```text
模块：视频生产 / 素材归类
范围：素材选择、上传和归类接口
目标：从当前浏览器所在电脑多选视频并完成归类
禁止：不要改 AI 视频，不触发付费生成
验收：文件窗口可打开，多选上传成功，归类结果可查询
执行：修改代码，跑测试和前端构建，提交 Git
```

任务描述优先包含：模块、范围、目标、禁止、验收、执行。前端细节可再补充页面、区域、元素文字、当前问题和期望效果。

## 当前模块

- 视频生产：生产总览、素材归类、内容文库、背景音乐、剪映草稿。
- AI 视频：商品图上传、商品与宣传信息、用途与风格、分镜脚本、生成任务。
- 模型能力：后端配置和调用能力保留，不显示为独立业务入口。

图片生产已经清除，不应恢复其导航、API、服务或前端代码。历史数据库表和迁移链仅为兼容现有运行库而保留。

## 工程约束

- 一个任务只处理一个模块，跨模块依赖需要明确说明。
- 运行数据、上传文件、数据库、缓存和临时文件放到 `ops-workbench-runtime/`。
- 不提交 API Key、厂商凭据或生成媒体。
- 未经明确确认，不触发付费视频生成。
- 业务口径变化时同步更新模块文档、项目记忆和交接文档。
